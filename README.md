# Snack boi terminal game project 
## NOTE: The game is a hobby project for others to try out and serves as a spring board for the developer to learn various programming and git skills

## Prerequisites
* Have Python installed
* Have Python's **keyboard** module installed

## How to run
1. Clone the repository
2. Open the terminal at the root directory
3. Run the game using ```python -u main_game.py``` or ```py -u main_game.py```


## About
The game is about a hungry guy who has an insatiable appetite. Once he has eaten
all the snacks in one area, he moves out to the next area to continue his eating
spree. However, as he progresses, something or someone will stand in his way.

The main goal of the game is to naviagte the stage as the snack boi 'O' and eat
certain number of snacks '*' to clear the stage. Per now, there is no way to 
lose a game. 

The game section contains two modes; classic mode and endless mode. The main 
difference is, as the names suggest, that endless mode can be played endlessly 
until the player decides to quit. Classic mode has a fixed number of snacks to 
eat till the stage is cleared. When clearing a classic stage for the first time, 
the next level unlocks and endless mode for the cleared level gets unlocked. 

Furthemore, the game contains powerups to aid the player. Some of them appear
in the level, while others can be bought from shop. There is also an account to
keep an overview of one's own progression, and a save system to save progress and
inventory.

## Navigating the game
The game is naviagted and played purely by keyboard. Mouse is not needed. 
The UI for menu and gameplay is made entirely using ASCII characters. The ASCII 
based UI design is made to tell the user what key does what. If a key does 
not perform as described, please report the issue.

## How to play
WASD keys is used to move up, left, down, and right respectively. This is also
indicated in the gameplay screen. Move around the maze to collect snacks ```'*'```
The game also has powerups, which can be equipped before starting a stage. 
Upon entering a stage with a powerup, press 'e' to activate the powerup. 
*NOTE: Some powerups may need further activation using another key, this will*
*be described during gameplay while having that powerup equipped*
